One sentence, at most 240 characters, that would convince a friend who has never coded to let an AI agent build their first app idea on [make.fun](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3).

`main.py` (pure Python standard library) writes the pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Run it twice and the output is byte-identical.
